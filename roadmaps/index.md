### [Java Senior → Staff Engineer](/roadmaps/java-senior/)

A development roadmap for Java developers with ~4 years of experience, leading to Senior/Staff Engineer level specializing in Real-Time Trading Systems.

**Level:** Mid → Senior → Staff
**Format:** 76 sprints (4-8 weeks each)
**Estimated time:** 8-12 years
**Topics:**
- **Phase 1:** Backend Fundamentals + Integrations (HTTP, REST, WebSocket, RabbitMQ, Kafka)
- **Phase 2:** Java Concurrency & JVM (Memory model, GC, profiling)
- **Phase 3:** Go + Algorithms (Go basics, hash tables, heaps, LRU)
- **Phase 4:** Architecture (EIP, gRPC, CQRS, Event Sourcing, distributed systems)
- **Phase 5:** Low-Latency (ZGC, Disruptor, Chronicle Queue, SBE)
- **Phase 6:** Leadership (ADR, design reviews, SLO, mentoring)
